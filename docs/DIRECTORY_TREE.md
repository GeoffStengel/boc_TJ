## Directory Responsibilities

- **Root:** Website entry point and deployment files.
- **css/:** Global styles, components, and responsive design.
- **js/:** Product data, interactions, calculators, and tools.
- **images/:** Product photography and branding.
- **docs/:** Project documentation for developers and AI agents.
